# Getting help

Before asking, please check:

- the [README](README.md), especially *Supported ECUs*, *Quick start* and *Safety*;
- [docs/hardware.md](docs/hardware.md) for cables, adapters, Linux permissions and latency;
- [docs/definitions.md](docs/definitions.md) for ECU definition files;
- the [existing issues](https://github.com/emanuelemerlo/marelli-iaw-ecu-studio/issues?q=is%3Aissue), open and closed.

Then open an issue with the template that fits:

| You want to | Template |
| --- | --- |
| Report that something does not work | [Bug report](https://github.com/emanuelemerlo/marelli-iaw-ecu-studio/issues/new?template=bug_report.yml) |
| Share a session on a real car, working or not | [Real car report](https://github.com/emanuelemerlo/marelli-iaw-ecu-studio/issues/new?template=car_report.yml) |
| Ask for a new feature or ECU | [Feature request](https://github.com/emanuelemerlo/marelli-iaw-ecu-studio/issues/new?template=feature_request.yml) |

Questions are welcome in Italian or English. For communication problems, a line trace (`--trace file.txt` on the command line, or the line trace option in the application) almost always gets the fastest answer.

This is a hobby project maintained in spare time: there is no guaranteed response time and no support for diagnosing or repairing a specific car. For security problems see [SECURITY.md](SECURITY.md).
